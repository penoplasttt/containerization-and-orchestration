# Инцидент: утечка памяти в сервисе каталога

**Дата:** 2026-09-14
**Сервис:** catalog
**Симптом:** рост RSS-памяти, OOM-kill пода, рестарты

## Причина
Накопление ссылок на большие объекты в кэше без инвалидации. Кэш рос
бесконечно, пока под не убило по памяти.

## Как чинили
Добавили TTL и лимит размера кэша, ограничили размер объекта в кэше.

## Признаки для быстрой диагностики
- Монотонный рост памяти без стабилизации
- OOM-kill в логах kubelet
- Рестарты пода с растущим интервалом
- Свежий коммит, меняющий логику кэша
